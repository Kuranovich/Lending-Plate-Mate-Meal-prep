# Лендинг Plate Mate

Одностраничный сайт на чистом HTML/CSS/JS, две языковые версии. Английская версия собирается из русской одной командой: `node tools/build-en.js`.

```
index.html          — русская версия (исходник разметки и русские тексты)
en/index.html       — английская версия, СОБИРАЕТСЯ АВТОМАТИЧЕСКИ — не править вручную
tools/i18n-en.js    — английские тексты по ключам data-i18n
tools/build-en.js   — сборка en/index.html из index.html
assets/styles.css   — стили; фирменные цвета в :root в начале файла
assets/app.js       — цены, БЖУ, контакты (CONFIG), калькулятор, заказ, строки для обоих языков
images/             — логотип и фотографии
```

## Что нужно добавить

Положите файлы в папку `images/` с этими именами. Пока файла нет, на его месте видна заглушка с именем.

| Файл | Что это |
|---|---|
| `logo.svg` | официальный логотип из брендбука (пока его нет, выводится текстовый логотип) |
| `hero.jpg` | ✅ добавлено (три блюда в одном кадре) |
| `favicon.ico`, `images/icons/` | ✅ иконка вкладки и значок для телефона |
| `breakfast.jpg` | ✅ добавлено |
| `lunch.jpg` | ✅ добавлено |
| `dinner.jpg` | ✅ добавлено |

## Что нужно проверить перед запуском

- **Ответы в FAQ** о хранении, разогреве и аллергиях (`index.html`, отмечены `TODO`), а также их английские версии в `EN` (`faq.a*`).
- **Меню на 14 дней** — в `MENU` в начале `assets/app.js` (для каждого блюда русское и английское название).
- **Telegram**: чат открывается по username `okhealthyfood` (`CONFIG.telegram`) с подставленным текстом.
- **Цвета** в `:root` (`assets/styles.css`) — сверить с брендбуком.

## Как это работает

- Языки: русская версия — корень сайта, английская — `/en/`. Ссылки для рекламы:
  - RU: https://kuranovich.github.io/Lending-Plate-Mate-Meal-prep/
  - EN: https://kuranovich.github.io/Lending-Plate-Mate-Meal-prep/en/
  Старые ссылки `?lang=en` перенаправляются на `/en/`. У каждой версии свои заголовок, описание и превью ссылки (og-теги, картинка `images/og.jpg`).
- **После любой правки текста** в `index.html` или `tools/i18n-en.js` запустите `node tools/build-en.js` — он пересоберёт английскую версию и сообщит, если для нового текста нет перевода.
- Калькулятор считает по формуле Миффлина — Сан Жеора × коэффициент активности × цель (−15% / 0 / +10%). Если ориентир выходит за 1250–2200 ккал больше чем на 100 ккал, сайт предлагает обсудить подбор с менеджером. Данные никуда не отправляются.
- Заказ: сообщение с выбранным пакетом собирается автоматически, клиент может его отредактировать. WhatsApp и Telegram открываются с готовым текстом (`wa.me/…?text=` и `t.me/<username>?text=`). Для старых версий Telegram текст дополнительно копируется в буфер обмена.
